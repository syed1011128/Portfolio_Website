# 🌐 Personal Portfolio Website

A modern, responsive, and professional portfolio website built using **HTML5**, **CSS3**, and **JavaScript**. This portfolio showcases my skills, projects, experience, achievements, and contact information in a clean and interactive interface.

---

## 📖 Overview

This portfolio serves as my personal website where visitors, recruiters, and collaborators can learn more about me, explore my projects, and get in touch.

The website is designed with a modern dark theme, responsive layout, and smooth user experience.

---

## ✨ Features

- ✅ Responsive design (Desktop, Tablet & Mobile)
- ✅ Sticky navigation bar
- ✅ Hero section
- ✅ About Me section

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Open the project

Simply open `index.html` in your browser.

Or, if you use VS Code:

Install the **Live Server** extension and click **Go Live**.
